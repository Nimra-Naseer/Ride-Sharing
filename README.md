# 🚗 Tere App Landing Page

This is a responsive landing page website for a ride-sharing app concept called **Tere**.  
It is built using **HTML and CSS only** and works smoothly on mobile, tablet, and desktop devices.

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Flexbox  
- Responsive Design (Media Queries)  
- Google Fonts (Montserrat)

---

## 📱 Features

- Fully responsive design (Mobile, Tablet, Desktop)
- Modern and clean UI
- Hero section with app download buttons
- Green call-to-action section
- How it works section
- Benefits section
- Footer with download buttons

---

## 💡 Purpose

This project is created for learning and practice of:
- Responsive web design
- Flexbox layout
- UI structuring
- Real-world landing page design
